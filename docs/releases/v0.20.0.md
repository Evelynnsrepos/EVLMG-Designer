## What's new in 0.20.0

Still no generative AI: every idea and every stroke is yours.

**Git saving, one repository per project**
- **Connect GitHub** once in the Git sync window (it uses the GitHub login your Git already has). From then on every project gets its own **private** GitHub repository, named `egd-<project name>`, made for you.
- It gets the latest version when you open a project and saves to GitHub **in the background** when you leave it, so you can keep working. Closing the app waits until saving is done. This also fixes projects that were not saved to Git on close.
- **Sync to Git** and **Sync from Git**, in the Git sync window or in a project's menu on the start screen, do it right away. A **Git mark** next to each project's name on the start screen shows whether it is saved to Git. It turns red when the last try failed; hover it to see why.
- **Import from Git** on the start screen lists your projects on GitHub to pick from, or takes any repository address.
- Did you keep all your projects in one repository (0.19)? **Give each project its own repository** moves them to one each. The old repository stays as it is, as a backup.

**Private repositories only**
- Git saving only uses private repositories, on every host. Before it sets up, downloads or saves, it checks that the repository can't be read without a login.
- To show one project to the world, open Advanced in its Git sync window and allow a public repository. You confirm a red warning and type the project's name. The project then gets a red **Public** mark on the start screen.

**GitLab, Gitea, Forgejo, Codeberg and your own server**
- New **Settings → Git** tab with step-by-step login help for other hosts and SSH.
- **Check a repository address** tells you whether Git on this computer can reach a repository and whether it is private.
- Choose the branch for new repositories, the commit message (`{date}` becomes the date and time) and **Extra Git settings**, for example `http.sslVerify=false` for your own server with a self-made certificate.

**Search and your own presets**
- A **search box on the start screen** finds a project by its name or description.
- On the last step of a new project, a search box finds presets and tools, and **Save as preset…** keeps the tools you picked as your own preset. It shows up next to the built-in ones from then on.
- **Settings → Project presets** lets you rename presets, change their tools, add first tasks for the task board, or delete them.

**Settings with tabs**
- Settings now has tabs: General, Writing, Keys & Hotwheel, Project presets, Git and Plugins.
- The **search box** next to the tabs looks through every tab at once.

**Boards and buttons**
- **Hotkey hint mode**: a switch in the sidebar (and in Settings → General) shows each button's key in its corner.
- The **eraser** now works on Brainstorm and Map boards too.
- Text boxes on boards grow with their text. After you place a shape or a text box, the tool switches back to Select.

**Pictures in text**
- **Drop or paste pictures** straight into Writer and Wiki text.
- Linux: files dropped in from outside the app keep their files. File pickers open in a folder that still exists.

New guide page: Settings and your own presets. The Git sync guide page shows the new steps.
