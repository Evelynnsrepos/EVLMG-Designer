## What's new in 0.24.0: faster drawing on Linux

**Draw**
- **Smoother strokes on Linux.** Pen and mouse moves are now handled once per frame instead of one by one, so the drawing keeps up with fast mice and pen tablets. Every point still ends up in your stroke.

**Settings, General: Drawing speed (new)**
- **See which graphics card draws your pictures**, with a warning when the app is drawing without one.
- **Run drawing test** paints the same stroke on three test pictures and times every pen move. **Copy results** puts the numbers on the clipboard for a bug report. Nothing is saved or sent.
- **Graphics mode on Linux**: Use the graphics card (now always on), Older screen handover (for drivers where the window stays blank or drawing is very slow) or No graphics card. Takes effect after a restart.

**Also in this version**
- Everything from 0.23.6: the Card Designer picture import, snapping, fields that fill themselves, and the version number on the start screen.
