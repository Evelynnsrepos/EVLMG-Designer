## What's new in 0.32.1: tools open again

A small release with an important fix and a smoother board. Projects and the file format are unchanged, so everything opens as before.

**Card Designer, Spreadsheet, Draw and the Design Book work again**
- In the installed app, these tools (and the Design Book export) could stop with the message
  "'application/pdf' is not a valid JavaScript MIME type". Restarting did not help.
- The cause: part of the app's own code, the part that makes PDF files, was mistaken for a PDF file when the
  app loaded it. That code no longer looks like a PDF, so every tool loads normally again.
- Your projects were never touched by this. Just install 0.32.1 and keep working.

**Moving post-its no longer lags**
- On boards like Brainstorm, dragging post-its and other things only redraws what moves, so it stays smooth
  even on big boards.

**Behind the scenes**
- Building the app now stops with an error if any code file could be mistaken for a PDF again.
