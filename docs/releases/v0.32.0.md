## What's new in 0.32.0: Code Studio, a new start screen, safer backups

Write your Godot game's code right next to its design, sort the start screen into boxes, and get your drawings back
from every backup. Older projects open as before.

**Code Studio (experimental): a code editor for your Godot game**
- Open your Godot 4 game folder and edit its scripts with completion, hover help, errors, jump to definition and rename,
  straight from your own Godot (the open editor, or one started hidden in the background).
- Run the game (F5) or the open scene (F6), stop it with F8, and click an error in the output to jump to its line.
- Your design data works inside the code: item, character, enemy, quest and data-tool ids and translation keys complete
  as you type, hover shows the entry, Ctrl+click opens it, and wrong or deleted ids are underlined with a fix.
- Combo mode (off by default) adds sparks, a little shake, a combo counter and blips while you type.
- Your code stays in the game folder; nothing is copied into the project.

**Start screen sections**
- Your folders are now sections in boxes: make each one narrow or wide, short or tall, move it, rename it, and stack
  short ones next to a tall one. The button in a box's corner opens it full screen (Esc goes back).
  Recent projects sit in one row below. Ctrl+Z undoes start screen changes.

**Backups you can trust**
- Fixed: restoring a backup could bring back a Draw document without its picture. Replaced layer pictures are now
  kept until no backup needs them, so a restored backup has its drawings again.
- Backups go back a month: the last 10, plus one per day for a week and one per week for a month.

**When a tool crashes**
- A tool that runs into a problem now shows Reload this tool. Copy report copies what went wrong (app version, system,
  graphics card and the error) and Report on GitHub opens a new issue with it filled in; nothing is sent until you
  press Submit there. The report is also kept in crash.log in the app's data folder.

**Asset Pool, clearer**
- Assets are grouped by status with counts, show kind icons, and can be seen as a list or as big pictures. The picture
  comes first in the side panel, status is a menu and a step bar, pictures and files are in one section, and "Who,
  when, priority" folds away. Pasting a checklist guesses each asset's kind from its name.

**For other versions and the mobile app:** Code Studio adds the `code` document type (see docs/FORMAT.md). It only
stores the game folder and open tabs; the code itself stays in the game folder. Older versions open these projects but
don't know the new tool.
