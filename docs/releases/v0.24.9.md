## What's new in 0.24.9: spreadsheet and bleed fixes

**Card Designer**
- **Filling from a different spreadsheet works.** If your sheet calls the name column something else, like "Card name" or "Title", its rows now update the cards they name. Before, every row became a new card, all with the open card's name, and an extra field showed up under Fields. New cards also never copy the open card's name any more, and a column name used twice now makes "Notes" and "Notes 2" instead of two fields with the same name.
- **Bleed and size boxes keep what you type.** Typing 2.5 or clearing the Bleed, Width, Height or Corner box no longer jumps to 0 for a moment. With "Scale the design with the bleed" on, that used to shrink the whole design while you typed.
