## What's new in 0.19.0

Still no generative AI: every idea and every stroke is yours.

**Writer: Markdown Syntax**
- A new **Markdown Syntax** switch in each Writer document's header. Off by default; turn it on per document, or for every new document in Settings, Writer.
- With it on, format by typing symbols: `==highlight==`, `####` to `######` headings, `- [ ]` checklists, `> [!note]` callout boxes (also tip, warning, danger and more, foldable with `[!tip]-`), `%%notes to yourself%%`, `#tags`, footnotes with `^[note]` or `[^1]`, `[text](link)`, `![name](picture)`, `[[Name|other text]]` and `![[Name]]` jump cards.
- Pasted Markdown turns into formatting, tables included. Ctrl+Shift+V pastes it as plain text.
- **Import** turns Markdown files into new Writer documents, and `[[links]]` between them work right away.
- Markdown export writes the same symbols back, so other Markdown note apps can open your documents.
- Switching it off never loses anything: highlights, callouts and tags you made stay; only the typing shortcuts stop.
- New toolbar buttons for highlight, checklist and callout, and three Writer slices for the Hotwheel: Insert callout, Highlight and the switch itself.
- Notes to yourself and tags are left out of the word count, and spell check skips tags.
- New guide page: Typing shortcuts.

**Drop text files in**
- Drag `.txt` and `.md` files from your file manager into the app: each one becomes a new Writer document and opens. Markdown files come in formatted, with Markdown Syntax on.
- Linux: dropping a file from outside the app no longer crashes it. Dropping pictures onto boards and lists works as before.

**Git sync (one person, several computers)**
- Keep a project in your own Git repository, with the Git installed on your computer and your own Git login. Turn it on with Git sync in the sidebar.
- It gets the latest version when the project opens and saves to Git when the project or the app closes. Sync now does both right away.
- **Open from Git** on the start screen downloads a project onto a new computer and keeps it synced. One repository can also hold all your projects; they all show up on the start screen.
- Git sync never mixes versions. If the project changed on two computers without syncing in between, it asks: use the Git version (this computer's version is backed up first) or keep this computer's version.
- It is for one person only, and says so before it turns on. Sharing a project turns full Git sync off.
- A shared project can get a **Git backup** instead: one member's computer saves everyone's merged work to Git when they close it, and never takes anything from Git. The others see "Git backup by …" in Work together.
- Old backups and sharing settings never go into the repository. Files over 100 MB stop the sync (GitHub refuses them), files over 50 MB get a warning.
- New guide page: Git sync. The privacy policy has a line about it.

**New look**
- The app now uses the Lexend Deca font everywhere, built in, so it looks the same on every computer. The T in a tool's header still picks another font for that tool.

In a shared project, everyone needs 0.19 to see the new Writer formats.
