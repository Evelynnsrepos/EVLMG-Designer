## What's new in 0.19.0

Still no generative AI: every idea and every stroke is yours.

**Writer: Markdown Syntax**
- A new **Markdown Syntax** switch in each Writer document's header. Off by default; turn it on per document, or for every new document in Settings, Writer.
- With it on, format by typing symbols: `==highlight==`, `####` to `######` headings, `- [ ]` checklists, `> [!note]` callout boxes (also tip, warning, danger and more, foldable with `[!tip]-`), `%%notes to yourself%%`, `#tags`, footnotes with `^[note]` or `[^1]`, `[text](link)`, `![name](picture)`, `[[Name|other text]]` and `![[Name]]` jump cards.
- Pasted Markdown turns into formatting, tables included. Ctrl+Shift+V pastes it as plain text.
- **Import** turns Markdown files into new Writer documents, and `[[links]]` between them work right away.
- Markdown export writes the same symbols back, so other Markdown note apps can open your documents.
- Switching it off never loses anything: highlights, callouts and tags you made stay; only the typing shortcuts stop.
- New toolbar buttons for highlight, checklist and callout, and three Writer slices for the Hotwheel: Insert callout, Highlight and the switch itself.
- Notes to yourself and tags are left out of the word count, and spell check skips tags.
- New guide page: Typing shortcuts.

In a shared project, everyone needs 0.19 to see the new formats.
