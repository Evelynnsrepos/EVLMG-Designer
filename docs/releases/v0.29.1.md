## What's new in 0.29.1: a small tidy-up

A tiny release with one fix. Projects and the file format are unchanged, so everything opens as before.

**Storyboard and Pitch Deck: nothing spills out of its box**
- The Storyboard follows the width of its panel. When it sits next to another tool, the Sheet and Board stack
  cleanly instead of running past the edge.
- Text boxes grow with their text, Sound is a text box too, and long words wrap.
- Subtitles scale with the picture, and status labels no longer stretch.
- In the PDF storyboard sheet, long scene names and statuses get more lines instead of being cut.
- Pitch Deck slide text shrinks with a small preview instead of overflowing.

**Behind the scenes**
- More time for quick Git steps in the automatic tests, so the Windows build no longer fails by chance.
