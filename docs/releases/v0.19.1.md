## What's new in 0.19.1

A small fix for the Flatpak.

- **Git sync works in the Flatpak.** Open from Git and Git sync stopped with "Could not start Git", because the Flatpak's sandbox has no Git of its own. The Flatpak now uses the Git installed on your computer, with your own GitHub login, like the other downloads do.
- Everything else is the same as [0.19.0](https://github.com/Evelynnsrepos/Evelopment-Games-Designer/releases/tag/v0.19.0): the Writer's Markdown Syntax, Git sync, dropping text files in, and the new font.
