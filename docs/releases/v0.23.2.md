## What's new in 0.23.2: more Card Designer

**More cards, easier**
- **+ Card** now sits above the card, next to a list of every card in the deck to switch between them. Each new card uses the same design with its own name, stats and picture. The ◀ ▶ arrows (or Page Up / Page Down) step through the cards.

**Front and back colours**
- **Card colours** at the top of the Colours tab set the background of the front and the back on their own, also when the background layer is locked.

**Foil**
- Tick **Foil** in the Style tab to print an item in shiny foil, or **Foil layer** in the Colours tab for everything on a layer. Foil shows with a shine on the card.
- Export **Foil mask sheets (PDF)**: black where the foil goes, laid out like the print sheets, the file print shops use for foil. Card images + JSON adds a foil mask for every card.
