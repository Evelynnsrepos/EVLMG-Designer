## What's new in 0.27.0: the Vector tool (experimental)

**Vector (new, experimental)**
- **A new tool for clean shapes** that stay sharp at any size: inventory and skill icons, app icons, logos, buttons, health bars, panels and badges. One drawing gives you a 16 px icon and a 1024 px one.
- **Start by picking what you are making.** Each choice sets the right size, and you can change it later under Drawing size.
- **Live shapes:** box, circle, polygon, star, ring, heart, shield, cross, gear and speech bubble. They stay editable, with sliders like Rounded corners, Points and Inner size for a star, or Teeth for a gear. Text too.
- **One-click looks:** Flat, Game icon, Glossy and Outline only set the outline, shading and shadow in one go. Colours, fades to a second colour, outlines, shadows and see-through can be changed afterwards.
- **At game size:** a preview at 16, 32, 64 and 128 px on dark, on light and in an inventory slot, so you see right away if details get lost when it is small.
- **Layers** work like in the Card Designer.
- **Save as** PNG at the sizes you tick (several sizes come as one ZIP) or SVG.
- It is experimental: this is the first part. Joining and cutting shapes, a pen for your own curves, snapping, sprite sheets and button states come later.
