# Material Maker example materials

These `.ptex` files are example materials from [Material Maker](https://github.com/RodZill4/material-maker) by
Rodolphe Suescun and contributors, under the MIT License ([`LICENSE.md`](LICENSE.md)). Material Lab shows them in its
gallery as ready materials to start from (names and search words in `../material.ts`).

- Copied unchanged from `material_maker/examples/` at commit `7d6daae3c74c09720afe4138ce09699ab3591ce1`.
- Left out: examples that show 3D scenes, symbols or tools instead of a tiling material (3d_shapes, raymarching,
  doc_tools, load_effect, mandelbrot, materials, mmm_donuts, biohazard, halloween, pentagram, radiation, skulls).
- `gpu.test.ts` renders every map of every example here.
